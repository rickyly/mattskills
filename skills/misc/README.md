- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — 将测试文件中的 `as` 类型断言迁移到 @total-typescript/shoehorn。

- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — 配置 Husky pre-commit 钩子，集成 lint-staged、Prettier、类型检查与测试。
