# 开发中

仍在开发中的技能。它们尚未准备好发布——预期会有粗糙之处、破坏性变更以及被废弃的实验。在它们晋级到稳定分组之前，会被排除在插件和顶层 README 之外。

- **[decision-mapping](./decision-mapping/SKILL.md)** —— 把一个松散的想法转化为一张排好序的调查工单地图，然后逐个推进直至解决。User-invoked。
- **[review](./review/SKILL.md)** —— 沿两条平行轴审查自某一固定点以来的变更：**Standards**（diff 是否遵循仓库的编码标准？）与 **Spec**（diff 是否忠实实现了原始的 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** —— 以一段段节拍（beat）的旅程来塑造文章，采用「选择你自己的冒险」（choose-your-own-adventure）的方式。挑一个起始节拍，只写那一个节拍，然后转向下一个，直到文章抵达自然的结尾。
- **[writing-fragments](./writing-fragments/SKILL.md)** —— 一场拷问式会话，从你身上挖掘碎片（fragment）——形态各异的写作素材小块——并把它们追加到一份文档中，作为未来文章的原始素材。
- **[writing-shape](./writing-shape/SKILL.md)** —— 拿一份装着原始素材的 markdown 文件，逐段把它塑造成一篇文章，在每一步都为格式选择展开论证。
